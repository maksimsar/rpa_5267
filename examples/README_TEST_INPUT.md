# test_input.pdf

`examples/test_input.pdf` intentionally is not stored in the repository.

Before a live Puzzle RPA demo, add a real PDF document locally and pass its path to the block through `FILE_PATH`. Do not commit private documents, scans, invoices, contracts, tokens or screenshots with visible secrets.

Offline checks use:

- `examples/sample_response_yandex.json`
- `examples/expected_output.json`
- `PDFYandexVisionBlock/examples/demo_result.json`
